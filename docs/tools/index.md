# Tool guides

Self-contained reference chapters for every tool the course uses, written for someone who has never used it.
Each one explains what the tool is for, how to open or install it, the features you will use most, the errors
you will meet, and a one-page cheat sheet. Read a guide when its week starts; come back to it on the job.
