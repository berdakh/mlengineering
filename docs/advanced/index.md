# Advanced track

Optional, deeper material for after the 12-week course (or alongside it, when a topic grabs you).
It takes the portfolio project `flowguard` through research-grade evaluation and full engineering:
48 notebooks with auto-checked labs in `labs/`, real results on the SKAB testbed data, and the
reasoning behind every decision.

| | |
|---|---|
| [Advanced weekly plan](weeks/) | Eight blocks of six sessions plus review days |
| [Advanced notebooks](notebooks/) | All 48 notebooks, readable here and runnable in Colab |
| [Advanced schedule](schedule.html) | Every session with objective, deliverable and prerequisites |
| [How it is designed](design.html) | Target capabilities, weekly rhythm, prerequisites and the chosen stack |

Labs here are graded with `python wb.py check <session>` (or the check cell inside each notebook).
Reference solutions and the wrong submissions each check rejects are in `solutions/labs/`.
