# Solutions

Everything you should open **after** a real attempt, in one place.

| File or folder | Contents |
|---|---|
| [`exercises.md`](exercises.md) | Every guided lab and challenge: where its reference solution lives, and the wrong submissions its checks reject |
| [`checkpoints.md`](checkpoints.md) | Model answers to every notebook's assessment, the review days' retrieval sheets, and the diagnostic notes |
| [`labs/<session>/`](labs/) | Reference code (`lab/`, `challenge/`), wrong submissions (`mutants*/`), answers (`assessment_answers.md`) |
| [`diagnostic/`](diagnostic/) | Diagnostic reference work, per-section notes, and [`SCORING.md`](diagnostic/SCORING.md) |
| [`interview/`](interview/) | Rubrics and worked answers for the seven interview sets |

## Confidence markers

| | Meaning |
|---|---|
| ✅ **Executed** | The reference was run and passes its checks; every listed wrong submission was run and rejected |
| ✍️ **Rubric** | Written or spoken answers: compare against the rubric, wording will differ |

Numbers quoted from real-data runs (SKAB) come from the runs recorded in each lesson. On another machine,
results that depend on threads or library versions may differ slightly; use `requirements-lock.txt`.

## Should you look?

Open a solution only after a timed, honest attempt, and record that you did in `progress/notes.md`. Mark a
session **independent** only if you did not. The diagnostic (notebooks 01-02) and the final assessment
(notebook 48) are only informative if you have not read their solutions first.
