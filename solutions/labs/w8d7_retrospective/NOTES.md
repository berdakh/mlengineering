# w8d7 - reviewer notes (minimal)

`lab/` is a reference **example** that links to the course's reference artifacts so the checks can
run on it. A learner's portfolio must link to the learner's own work; reviewing it means opening a
sample of the linked artifacts and checking that the stated conditions are plausible (time, help,
review) - the checks only establish that the files exist.

Common weak submissions: capabilities silently omitted instead of listed as `not demonstrated`;
reference solutions cited as evidence; CV bullets with adjectives and no number; a next plan that is
a wish list without criteria or weekly deliverables.
