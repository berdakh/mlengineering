# Notebooks

Work through these in order, one per core day. Each builds on the last.

**Prefer to read them in a browser?** Every notebook is rendered on the
[course site](https://berdakh.github.io/mlengineering-/notebooks/), with a Colab button on each page.

Do not edit the `.ipynb` files directly: they are built from `notebook_src/*.py` (`make notebooks`).
Your own work goes in `labs/<session>/lab/` and `challenge/`, which the notebooks check.

The full table with Colab badges is in the [repository README](../README.md#the-notebooks).
