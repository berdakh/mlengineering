# 45 · ML system design — lab files

**The lesson is notebook [`45_system_design`](../../advanced/notebooks/45_system_design.ipynb)** ([read it on the course site](https://berdakh.github.io/mlengineering/advanced/notebooks/45_system_design.html), [run it in Colab](https://colab.research.google.com/github/berdakh/mlengineering/blob/main/advanced/notebooks/45_system_design.ipynb)).

This folder holds the files that notebook uses. You edit `lab/` and `challenge/`; the notebook runs the checks.

| Folder | Contents |
|---|---|
| [`challenge/`](challenge/) | independent challenge starter |
| [`checks/`](checks/) | automated checks for the guided lab |
| [`checks_challenge/`](checks_challenge/) | automated checks for the challenge |
| [`example/`](example/) | worked-example scripts the notebook runs |
| [`figures/`](figures/) | figures and the script that regenerates them |
| [`hints/`](hints/) | progressive hints (also inside the notebook) |
| [`lab/`](lab/) | guided-lab starter: the files you edit |

Check from a terminal: `python wb.py check w8d3` (add `--challenge` for the challenge). Reference solutions: `solutions/labs/w8d3_system_design/` — attempt first.
