# 46 · Coding and SQL interviews, timed — lab files

**The lesson is notebook [`46_coding_interviews`](../../notebooks/46_coding_interviews.ipynb)** ([read it on the course site](https://berdakh.github.io/mlengineering-/notebooks/46_coding_interviews.html), [run it in Colab](https://colab.research.google.com/github/berdakh/mlengineering-/blob/main/notebooks/46_coding_interviews.ipynb)).

This folder holds the files that notebook uses. You edit `lab/` and `challenge/`; the notebook runs the checks.

| Folder | Contents |
|---|---|
| [`challenge/`](challenge/) | independent challenge starter |
| [`checks/`](checks/) | automated checks for the guided lab |
| [`checks_challenge/`](checks_challenge/) | automated checks for the challenge |
| [`data/`](data/) | data and generators for this session |
| [`example/`](example/) | worked-example scripts the notebook runs |
| [`figures/`](figures/) | figures and the script that regenerates them |
| [`hints/`](hints/) | progressive hints (also inside the notebook) |
| [`lab/`](lab/) | guided-lab starter: the files you edit |

Check from a terminal: `python wb.py check w8d4` (add `--challenge` for the challenge). Reference solutions: `solutions/labs/w8d4_coding_interviews/` — attempt first.
