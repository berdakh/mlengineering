# Your progress

* `progress.json` - four independent flags per unit, written by `python wb.py mark ...`:
  `reading` (reading completed), `guided` (guided practice completed),
  `independent` (independent skill demonstrated), `review` (review needed).
* `notes.md` - dated notes appended by `python wb.py note <unit> "..."`; free-form, edit at will.
* `SKILLS_LEDGER.md` - what is demonstrated, self-reported, or unassessed. Updated only from
  real submissions.

Commit these files; they are the persistent record of the course. Running supplied code
or passing supplied checks is recorded as *guided*, never as *independent*.
