# w1d6 lab starter

| File | Purpose |
|---|---|
| `explore_skab.py` | the notebook export you are refactoring (cells marked `# %%`); run it from the course repository root |
| `COMMIT_REVIEW.md` | self-review rubric for your commit history; copy it into your project, fill it in, commit it |

Work in your own repository outside the course repository (see section 4 of the lesson) and grade
it with `WB_TARGET_DIR=<your repo>`. This directory deliberately contains no project, so the checks
fail against it as shipped.

There is no `.ipynb` here: the export is the artefact you would be handed in practice once a
notebook leaves its author's machine, and it diffs cleanly in Git.

All numbers the notebook prints are claims to be audited. Several are wrong.
